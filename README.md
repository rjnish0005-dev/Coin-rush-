# CoinRush Complete Demo

Virtual-coin-only multiplayer Heads/Tails prototype with:
- Login
- Admin panel
- User management
- Admin credit/debit
- SQLite database
- Coin ledger
- Socket.IO live aggregate stats
- 30-second rounds
- Server-side cryptographic random result

## Start
Node.js 18+:
npm install
npm start

Open http://localhost:3000

Demo admin:
username: admin
password: admin123

Change the admin password and SESSION_SECRET before any real deployment.

This is a demo. It does not implement real-money payments, withdrawals, cash-out, or manipulated outcomes.
